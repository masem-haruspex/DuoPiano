# DuoPiano
A React + Java Spring web app for playing piano in a 3d enviorment with another player. Uses WebSocket for messaging and note signals.

The app is split into a Frontend and a Backend composed of 3 Microservices:

Frontend: https://github.com/masem-haruspex/DP_FrontEnd

Backend Authentication: https://github.com/mkepg/DP_Authentication

Backend Messaging: https://github.com/masem-haruspex/DP_Messaging

Backend Rooms: https://github.com/masem-haruspex/DP_Rooms
